# Recipe App

## المتطلبات لتشغيل المشروع محلياً (VS Code)

لضمان عمل النظام بشكل كامل (وخاصة رفع الصور)، يجب إعداد المتغيرات البيئية بشكل صحيح:

1. انسخ ملف \`.env.example\` إلى ملف جديد باسم \`.env\` في جذر المشروع.
2. ضع بيانات Cloudinary الخاصة بك في ملف \`.env\`:
   \`\`\`env
   CLOUDINARY_CLOUD_NAME=اسم_الكلاود_الخاص_بك
   CLOUDINARY_API_KEY=مفتاح_api_الخاص_بك
   CLOUDINARY_API_SECRET=السر_الخاص_بك
   \`\`\`
   **(ملاحظة: هذه المتغيرات للاستخدام في الخادم - Server Side ولا تستخدم \`VITE_\` لتجنب كشف \`API_SECRET\` للمتصفح).**
3. شغل الأمر \`npm install\` لتثبيت الحزم.
4. شغل المشروع باستخدام \`npm run dev\`.

سيعمل الخادم الآن محلياً، وستتمكن من الرفع إلى Cloudinary بنجاح.
